# Ride Booking Analytics Dashboard

# Project Overview
This project is an interactive Power BI dashboard created to analyze ride booking data and generate business insights.

The dashboard helps track:
- Total Trips
- Total Revenue
- Average Distance
- Average Passengers
- Monthly Trip Trends
- Revenue by Car Type
- Trips by City
- Location Analysis

---

# Tools Used
- Power BI
- Data Cleaning
- Data Visualization
- Dashboard Design

---

# Dashboard Pages

## 1. Overview
Contains KPI cards, payment analysis, and revenue insights.

## 2. Trends Analysis
Shows trip trends by month and city-wise booking analysis.

## 3. Location Analysis
Displays trip distribution using map visualization.
